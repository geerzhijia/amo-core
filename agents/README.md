# Agent roles

No agents are implemented or running. Role documents specify expectations, not
credentials, access grants, or executable instructions that override governance.
The [CEO role](ceo/identity.md) is the sole initial role definition.

Research, finance, operations, engineering, and compliance subagents are
**DEFERRED**. Their future mandates must specify scope, accountable owner,
permissions, escalation rules, evidence outputs, and revocation. Delegation can
never transfer authority the delegator does not possess.
